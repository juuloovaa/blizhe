# Ближе — список экранов MVP

## Системные / вход

| ID | Экран | Описание |
|----|--------|----------|
| S01 | Loading | Проверка `initData`, загрузка профиля |
| S02 | Onboarding Mode | Выбор: «Я один/одна» / «Я в паре» |
| S03 | Onboarding Profile | Отображаемое имя, местоимения (опционально) |
| S04 | Invite Confirm | Подтверждение приглашения в пару по deep link |

## Нижняя навигация (5 табов)

| Tab | Экран | Маршрут |
|-----|--------|---------|
| Главная | Home | `/` |
| Карточки | Cards | `/cards` |
| Тесты | Tests | `/tests` |
| Помощник | Assistant | `/assistant` |

## Главная

| ID | Экран | Описание |

| ID | Экран | Описание |

## Профиль и пара

| ID | Экран | Описание |
|----|--------|----------|
| P01 | Profile | Имя, местоимения, режим, аватар Telegram |
| P02 | Edit Profile | Редактирование отображаемого имени и местоимений |
| P03 | Couple | Статус пары, пригласить / отменить / отключиться |
| P04 | Invite Share | Показать ссылку + Share |
| P05 | Notifications | Тумблеры типов уведомлений |
| P06 | Privacy | Пояснения + удаление общих данных пары |

| P08 | Block Partner | Подтверждение блокировки |

## Модальные / системные оверлеи

- Confirm dialogs (отмена invite, отключение пары, блок, удаление).
- Toast / haptic confirmation.
- Telegram MainButton для primary CTA на вложенных экранах.
